TRANSFER TO ANOTHER COMPUTER

1. Install XAMPP at C:\xampp and copy the entire Cybersecurity folder to C:\xampp\htdocs\Cybersecurity.
2. Start MySQL and Apache in XAMPP Control Panel.
3. Double-click Setup Database.bat. If Windows refuses email-task registration, run the batch file as Administrator.
4. Open http://localhost/Cybersecurity/.
5. In Gmail Alerts, enter the Google app password belonging to alimaomadelyn@gmail.com, enable Automatic notifications, and save.
